# Night Repair App Demo

夜后修复是一个面向熬夜人群的睡眠恢复与生活修复 Demo。当前 GitHub Pages 版本保留模拟 Agent 效果，不包含真实 API Key。

## Demo 功能

- 今日首页：智能综合分析、恢复指数、时间线补救
- 睡眠记录：根据入睡和起床时间计算熬夜等级、睡眠债
- 饮食建议：基于今日状态给出外卖、一人餐、夜宵建议
- 今日补救：睡眠、咖啡、饮食、任务安排建议
- 轻运动：基于熬夜状态推荐低负担恢复动作
- 睡前舒缓：呼吸训练和待办清空
- 7 日报告：熬夜模式、饮食和睡眠关系洞察

## GitHub Pages

静态页面入口为 `index.html`，可直接通过 GitHub Pages 从 `main` 分支根目录部署。

## API 说明

当前在线 Demo 使用模拟 Agent，不在前端存放真实 API Key。真实模型调用应通过后端代理完成，避免密钥暴露。
